## Open source

### [`pi-memctx`](https://github.com/weauratech/pi-memctx)

Local-first memory context for Pi coding agents.

It helps agents load, search, and persist project knowledge across sessions using Markdown packs — so they can start with useful context instead of rediscovering the same project every time.
